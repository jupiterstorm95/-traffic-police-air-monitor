# Air Pollution Exposure Monitor for Traffic Police
### Ali Akbar Zaidi | Lahore, Pakistan

An ESP32-based project investigating roadside air pollution exposure among traffic police. The device combines particulate and MQ gas sensors with data logging and Wi-Fi telemetry.

Ten devices were deployed through collaboration with Punjab government authorities, alongside surveys of more than 30 traffic officers.

## Technical approach
- ESP32 firmware for sensor readings and data collection
- UART communication with the particulate sensor
- MQ gas-sensor integration
- Wi-Fi transmission for remote monitoring

## Project documentation
This repository is being organised to bring together firmware, circuit schematics, PCB design files, device photographs, measurement records and policy recommendations. Materials will be added as they are prepared for public sharing.

## Measurement notes
Recorded measurements will be distinguished from demonstration data. Raw gas-sensor outputs require appropriate calibration before interpretation as pollutant concentrations.
